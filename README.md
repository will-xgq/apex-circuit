# Apex Circuit · 纽伯格林北环

原生 WebGPU 赛车游戏。在支持 WebGPU 的浏览器中，驾驶奥迪 R8 挑战纽伯格林北环。

**[在线试玩](https://will-xgq.github.io/apex-circuit/)** · [观看 30 秒实机宣传片](https://will-xgq.github.io/apex-circuit/exports/Apex-Circuit-北环实机宣传片-30s.mp4)

第一次玩可以选「自由计时」，按住 **W** 或触屏油门起步，按 **C** 或点「视角」切换座舱和追车镜头。

在本地运行 `npm start` 后即可驾驶。[打开本地赛道](http://127.0.0.1:8765/)

北环单圈 20.832 公里，从 T13 起算。赛道采用 OpenStreetMap 路线与路宽、高程地形、按弯率分布的红白路肩和两处带倾角的混凝土槽。三圈竞速的六台车共用同一份 R8 模型和动力学。对手操作油门、刹车和方向，按同样的轮胎抓地、换挡、路肩与护栏约束行驶。新手赛按教练的练习配速组织。自由计时可单独练习。教练显示下个弯的方向、距离、模拟参考入弯与出弯速度，并在过弯后显示本次实测。教练按钮可切换屏幕提示、中文语音和关闭。语音使用浏览器的系统语音服务。

「T13 P 房出站」将车放在 13 号看台前的维修通道。按 W 或触屏油门沿实际出口并入北环，出站引导将车速控制在约 60 km/h。第一圈是出站圈，下次通过 T13 计时线才开始正式计时。

赛道周边使用德国莱茵兰－普法尔茨州的 DOP20 正射航拍。依照地图中的建筑轮廓重建 T13 看台、工场和车库，森林与灌木边界限制植被分布。护栏距离来自沿赛道每八米与地图防护设施的交点，缺测段以邻段或路宽估算。实际 T13 位置设置横向计时线，路旁的识别牌、临时维修棚和工位工具为模拟场景建模。

| 输入 | 驾驶操作 |
| --- | --- |
| W / ↑ 和 S / ↓ | 油门、制动，低速继续按刹车可倒车 |
| A / D 或 ← / → | 转向 |
| Space | 手刹 |
| Q / E | 降挡 / 升挡，进入手动模式 |
| M | 自动与手动换挡 |
| C | 头盔座舱、低位追车、高位追车、车头视角 |
| V | 开关座舱内的踏板小窗 |
| H | 切换教练模式 |
| B / L | 切换新手辅助 / 单独开关路线 |
| R / Esc | 回赛道 / 暂停或继续 |

触屏可使用方向、手刹和踏板按钮，也可以在座舱下半部横向拖动方向盘。四个轮胎独立读取柏油、路肩、草地与混凝土地面。七挡双离合的转速、换挡时机与油门负荷共同驱动仪表和实录声浪。头盔、手套、赛车鞋和内饰通过带透明通道的图层在 WebGPU 中合成。R8 拆解入口保留了可旋转的三维外部模型。

新手辅助默认开启。自由计时中可按住 W 或触屏油门熟悉全圈。路面上的绿色箭头提示加速，黄色提示收油，红色提示制动。教练并排显示当前车速与当前建议速度。短按方向键微调，持续按压会逐渐增大转向幅度。新手模式提供循线修正和超速入弯制动，B 切换专业驾驶，L 单独开关路线。

运行 `npm test` 可验证车辆、路肩、护栏、教练计时与圈数。赛道、声音许可及派生数据见[署名页](./credits.html)。驾驶参考速度、路面横坡与视觉场景均为本模拟器的近似值。
